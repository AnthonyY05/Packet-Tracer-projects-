# Small Office Network – Cisco Packet Tracer
## Network Topology

![Small Office Network Topology](topology%20SON.png)

## Overview

I built a small office network using Cisco Packet Tracer to practise basic networking and IT support skills.

## Network Setup

The network includes:

- 1 Cisco 2811 Router
- 1 Cisco 2960 Switch
- 5 PCs
- DHCP

## Configuration

I configured the router with:

- IP address: 192.168.1.1
- Subnet mask: 255.255.255.0
- DHCP for automatic IP addressing
- Default gateway: 192.168.1.1
- DNS server: 8.8.8.8

The PCs were configured to receive their IP addresses automatically using DHCP.

## Testing

I tested the network using:

- `ipconfig`
- `ping`

I tested connectivity between the PCs and the router to make sure the network was working correctly.

## Skills Practised

- IP addressing
- DHCP
- Subnetting
- Router configuration
- Switch configuration
- Network connectivity testing
- Basic troubleshooting
- Cisco Packet Tracer

## Project Outcome

The PCs were successfully connected to the network and received their IP configuration automatically through DHCP. Connectivity was confirmed using ping tests.
